# جدولي الذكي — منظّم الجداول المدرسية

موقع لبناء الجدول المدرسي للمدارس الابتدائية (6 صفوف، كل صف فيه عدة فصول).
يوزّع الحصص تلقائياً في أقل من ثانية، ويكشف التعارضات لحظياً، ويتيح التعديل بالسحب والإفلات:
عند سحب أي حصة تتلون **الخانات المتاحة بالأخضر** و**الخانات المتعارضة بالأحمر**، مع شرح سبب التعارض.

## التشغيل (بدون أي تثبيت)

**الطريقة الأسهل:** افتح ملف `index.html` بالضغط عليه مرتين (Chrome أو Edge أو Firefox).
على ويندوز يمكنك أيضاً تشغيل `start.bat`.

**أو عبر سيرفر محلي** (اختياري):

```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

> عند أول تشغيل تُحمَّل بيانات تجريبية لمدرسة ابتدائية (6 صفوف × 3 فصول، 32 معلماً، 11 مادة).
> اضغط **«توليد تلقائي»** لترى الجدول يُبنى، ثم جرّب سحب الحصص.
> لبدء مدرستك: **المواعيد والإعدادات ← بدء مدرسة جديدة**.

## خطوات الاستخدام

1. **المواعيد والإعدادات**: أيام الدراسة، عدد الحصص، بداية اليوم، مدة الحصة، والاستراحة.
2. **الصفوف والفصول**: عدد الفصول لكل صف، والقاعة الثابتة لكل فصل، والأوقات المتاحة للصف (مثلاً انصراف مبكر يوم الخميس).
3. **القاعات**: الفصول والمعامل والملاعب وغرف الموسيقى والفنون.
4. **المواد**: عدد الحصص الأسبوعية لكل صف، والقاعة التي تحتاجها المادة (مثلاً الحاسب ← معمل الحاسب)، وأقصى عدد حصص في اليوم.
5. **المعلمون**: المواد التي يدرّسها كل معلم، والصفوف التي يدرّس لها، ونصابه الأسبوعي، وأوقات عدم تواجده.
6. **توزيع المواد**: من يدرّس كل مادة في كل فصل. المادة الواحدة يمكن توزيعها على أكثر من معلم، مع زر للتوزيع التلقائي الذي يوازن الأنصبة.
7. **الجدول الذكي**: توليد تلقائي، ثم تعديل يدوي بالسحب والإفلات.

## المزايا

- **توليد تلقائي ذكي**: يرتب الحصص من الأصعب للأسهل، ويحل الانسدادات بسلاسل الإزاحة، ثم يحسّن الجدول لتقليل الفراغات بين حصص المعلم وتوزيع المادة على أيام الأسبوع.
- **سحب وإفلات مع تلوين فوري**:
  أخضر = متاح • أصفر = متاح مع ملاحظة • أزرق = تبديل مع الحصة الموجودة • أحمر = تعارض (مع سبب واضح: المعلم مشغول مع فصل آخر، القاعة محجوزة، تجاوز الحد اليومي…).
- **النقل بالضغط**: اضغط على الحصة ثم على الخانة الخضراء (مناسب أيضاً للشاشات اللمسية).
- **تثبيت الحصص 🔒**: الحصة المثبتة لا يحركها التوليد التلقائي.
- **4 طرق عرض**: جدول الفصل، جدول المعلم، جدول القاعة، ونظرة عامة على المدرسة كلها (بالفصول أو بالمعلمين). عند المرور بالماوس على أي حصة تُبرز كل حصص نفس المعلم.
- **مركز التنبيهات**: التعارضات، والحصص غير الموزعة وسببها، والمواد بدون معلم، والمعلمون الذين تجاوزوا النصاب، والفصول أو القاعات التي لا تكفي أوقاتها، والمواد التي يستحيل توزيعها بسبب الحد اليومي.
- **من المتاح الآن؟**: لمعرفة المعلمين المتاحين في أي حصة (مفيد للحصص الاحتياطية).
- **طباعة / PDF** لكل الفصول أو كل المعلمين أو القاعات، و**تصدير Excel**.
- **تراجع وإعادة** (Ctrl+Z / Ctrl+Y) لكل خطوة.
- **حفظ تلقائي** في المتصفح، مع تصدير واستيراد نسخة احتياطية (JSON) لنقل البيانات لجهاز آخر.

## هيكل الملفات

```
index.html        الصفحة الرئيسية
css/style.css     التصميم
js/engine.js      محرك القيود واكتشاف التعارضات والمولّد التلقائي (يعمل أيضاً في Node)
js/store.js       البيانات، الحفظ، التراجع، البيانات التجريبية، التوزيع التلقائي على المعلمين
js/ui.js          الأيقونات والإشعارات والنوافذ والمؤثرات
js/pages.js       صفحات البيانات (لوحة التحكم، المواعيد، الصفوف، القاعات، المواد، المعلمون، التوزيع)
js/timetable.js   صفحة الجدول: العرض والسحب والإفلات والتوليد والطباعة والتصدير
js/main.js        التنقل، الشريط العلوي، مركز التنبيهات، التشغيل
```

البيانات تُحفظ في متصفحك فقط (localStorage)، ولا يُرسل أي شيء إلى الإنترنت.
